# Project One: Business Requirements Document

This project demonstrates how stakeholder needs can be translated into clear, actionable system requirements. The document analyzes the DriverPass client interview and defines the proposed system’s functional, nonfunctional, and user-interface requirements.

The artifact also addresses system assumptions, limitations, security considerations, employee and customer workflows, and a development schedule for the proposed web-based system.

## Skills Demonstrated

- Business and stakeholder requirements analysis
- Functional and nonfunctional requirement development
- User-interface requirement planning
- Security and role-based access considerations
- Project scheduling with a Gantt chart
- Technical documentation for system design
